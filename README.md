# LOST SIGNAL

A browser-based first-person island survival and exploration game.

## Stack

- React for the interface and HUD
- Vite for development and builds
- Three.js for the 3D world
- JavaScript (ES modules), no TypeScript

## Development

```bash
npm install
npm run dev
```

## Current milestone

Milestone 1 establishes the project structure and a minimal playable 3D scene. The original island prototype will be integrated in the next milestone.
